# Jotta Edit v1.0.0 — Code syntax theme references

These presets are **inspired by** well-known themes. The token groups and contrast have been adapted to Monaco's grammars; colours may differ from a theme installed natively in Sublime Text or VS Code. No external theme executable or extension is bundled.

- Sublime Text: Mariana, Monokai, Celeste and Breakers palettes. Examples: https://github.com/twolfson/sublime-files/tree/master/Packages/Color%20Scheme%20-%20Default
- VS Code classic Dark+ / Light+: https://github.com/microsoft/vscode/tree/main/extensions/theme-defaults/themes
- GitHub Default: https://github.com/primer/github-vscode-theme
- Monokai Pro: https://monokai.pro/
- Mariana Pro: https://github.com/n0rmand0/Mariana-Pro-color-theme

Palette changes affect only the editor syntax presentation, not Explorer, menus or the window frame.

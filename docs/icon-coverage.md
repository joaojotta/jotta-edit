# Explorer icon coverage — v1.0.0

The Explorer chooses icons by extension and category. User-supplied SVGs are used directly, with per-type colour overrides available from Preferences.

| Icon | Used for |
|---|---|
| folder.svg | folders |
| file.svg | fallback / other files |
| html5.svg | html, htm |
| css3.svg | css, scss, less |
| js.svg | js, jsx, mjs, cjs, ts, tsx |
| json.svg | json, jsonc |
| php.svg | php, phtml |
| txt.svg | txt, md, markdown |
| fonts.svg | ttf, otf, woff, woff2, eot |
| png.svg | png |
| jpeg.svg | jpg, jpeg |
| gif.svg | gif |
| svg.svg | svg |
| webp.svg | webp |
| image.svg | bmp, ico, avif, tif, tiff |
| audio.svg | mp3, wav, flac, ogg, m4a, aac |
| video.svg | mp4, webm, mkv, avi, mov |
| package.svg | zip, rar, 7z, tar, gz, bz2, xz |

Auxiliary UI icons supplied by the user and included in the build:

- folder-add.svg
- refresh.svg
- formatter.svg
- search.svg
- command.svg
- theme.svg
- close.svg
- sidebar-fold.svg
- sidebar-unfold.svg

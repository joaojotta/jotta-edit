# Jotta Edit 0.0.12 Beta — release notes

## Changes

- CSS colour selectors are injected inline as visible, clickable coloured-square
  glyphs before the colour code. The colour picker remains unchanged.
- Matching HTML, XML, JSX/TSX and PHP/HTML tag names are underlined at both ends,
  without highlighting the `<` or `>` delimiters.
- Double-click an **empty** area of the tab strip for New File.
- Added Portuguese (Portugal) translation for app-owned controls, menus and many
  status messages; OS default, pt-PT and English are available from Preferences
  and change live. Monaco's own popups and some system-native labels may still
  appear in English.
- Imported all 13 supplied SVG Explorer file/folder icons; Explorer shortcut
  icons use theme-friendly light/dark display filtering.
- Integrated the user-provided Jotta Edit logo into Linux icon sizes, Windows
  ICO, and the in-app icon.

## Verification

- Node source syntax/configuration checks and local test suite passed.
- The complete Flatpak build, Windows installer build and live Monaco rendering
  still require validation on their target platforms.

## Building

Linux: `./scripts/build-flatpak.sh`

Windows PowerShell:
`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\\scripts\\build-windows.ps1`
